name=QGIS2Mapbender
description=QGIS plugin to populate Mapbender with WMS services from QGIS Server using the Mapbender API.
about=This QGIS plugin exports your QGIS project as a WMS served by QGIS Server and publishes it in a Mapbender application (https://mapbender.org).
 It supports both local QGIS projects and projects stored in PostgreSQL, as well as local data and data stored in PostgreSQL.

 Requirements:
 - QGIS2Mapbender 1.0.0 or later requires Mapbender 4.1.2 or later.
 - QGIS Server and Mapbender must be installed on the server. QGIS Server and Mapbender can also be run as Docker containers.
 - Local projects must be saved in the same folder as their data. PostgreSQL projects or data sources require a local pg_service.conf file.
 - Configure Mapbender's api_upload_dir, an application with a "main" layerset or the configured custom layerset, and the required user permissions. For further information, see the README.

 Detailed documentation, including Apache, PHP and Docker configuration, is available at https://github.com/WhereGroup/QGIS2Mapbender/blob/main/README.md.
